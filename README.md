# What are you going to do? · 나의 계획 말하기

6학년 영어 **9단원 What are you going to do?** 학습용 웹앱입니다.
질문 5개로 친구의 계획을 묻고, **I'm going to ___.** 로 나의 계획을 말하며 익힐 수 있도록 만들었습니다.
(5학년 *K_FOOD_INTRODUCTION*, 6학년 *Can you come to the ___?* 와 같은 구성, ⛄✈️ 겨울방학·여행 테마)

## 주요 표현

| 역할 | 표현 |
|------|------|
| 묻기 | **What are you going to do** this afternoon / tonight / tomorrow / this weekend / this winter vacation**?** |
| 대답 | **I'm going to ___.** (기본) · I'm going to fly a kite **at the park**. (도전) |
| 맞장구 | Sounds fun! · That's great! · Have fun! · Have a good time! · Wow, me too! |

## 기능

- ❓ **질문하기** — 질문 5개 카드(실제 사진) + 표현 정리
- 🎨 **활동 카드** — 활동 **43개**, 기본 / 도전(누구와·어디서) 문장
  - 🏠 집·학교 10 · ⚽ 운동·놀이 12 · 👨‍👩‍👧 가족과 함께 10 · ✈️ 가족 여행 11
    (제주도, 부산 해운대, 경주 불국사, 설악산, 전주 한옥마을, N서울타워, 강릉 해돋이, 화천 얼음낚시 축제, 기차 여행, 일본, 호주)
  - **언제** 필터: 그때 하기 좋은 활동만 보기 (예: 겨울방학 → 스키, 눈썰매, 여행…)
- 💬 **대답하기** — 질문(언제) + 할 일 + 맞장구를 골라 3줄 대화 완성 · 🎲 무작위
- 🗓️ **내 계획표** — 질문 5개마다 할 일 1개 고르기(⭐ 추천 표시, 어색한 조합은 🤔 안내)
  - 📝 나의 계획표(이름 입력) · 🖨️ 계획표만 인쇄
- 🎤 **연습 · 짝 활동** — 👫 친구 인터뷰 기록표(친구 대답 적기, 맞장구 체크) + 계획별 대화 줄마다 🎙️ 말하기 정확도, 🎭 역할극(A 질문 / B 대답)
- 🧩 **사진 퀴즈** — 질문을 듣고 사진에 맞는 `I'm going to ___.` 고르기, 맞히면 따라 말하기
- 단어 클릭 시 **뜻 풍선 + 발음**, 말하기 **속도 조절**

## 사진

카드의 사진은 브라우저에서 **위키백과(Wikimedia Commons) 대표 사진**을 불러와 보여 줍니다(인터넷 연결 필요, 7일 동안 브라우저에 저장).
사진을 불러오지 못하면 이모지 그림이 대신 보이고, 상단 **📷 실제 사진** 버튼으로 끌 수도 있습니다.
직접 찍은 사진을 쓰려면 `images/` 폴더에 넣고 `data.js` 의 해당 활동에 `photo: "images/파일.jpg"` 를 추가하세요.

## 사용 방법

`index.html`을 브라우저(크롬 권장)에서 열면 됩니다. 별도 설치가 필요 없습니다.
음성은 브라우저 내장 **Web Speech API**(음성 합성·음성 인식)를 사용하고, 계획표·인터뷰·연습 기록은 localStorage에 저장됩니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조(탭·섹션) |
| `style.css`  | 디자인·겨울방학 테마 |
| `data.js`    | 질문 5개, 활동 43개(사진 키워드·추천 시기·도전 표현), 맞장구, 단어 뜻 |
| `app.js`     | 음성·사진·단어 풍선·계획표·인터뷰·역할극 채점·퀴즈 로직 |
